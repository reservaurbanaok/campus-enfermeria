The Campus Web remains the public information and conversion surface. The OMEGA
assistant CTA opens the official WhatsApp channel; no local Web chat, Web
session, Web proxy, or Web conversational runtime is part of the public site.

flow, WhatsApp runtime, Instagram runtime, Core PROD, Railway, Meta, n8n, and
NETROOM. No real messages or social canaries were sent.

conversational standard and added complexity without equivalent value to the
OMEGA LIVE experience already operating through WhatsApp and Instagram.

Kaizen decision: remove the lower-value complexity and concentrate
conversation on the channel with the strongest verified experience.
