**Versión:** 1.0
**Estado:** Desarrollo local completado, pendiente de aprobación visual

---

## Preview local

### Servidor HTTP corriendo
Puerto **8888** activo.

### URLs de acceso

**Desde tu computadora:**
```
http://localhost:8888
http://127.0.0.1:8888
```

**Desde celular (misma red WiFi):**
```
http://192.168.0.253:8888
```

---

## Instrucciones para ver en celular

1. Conectá tu celular a la misma red WiFi que tu computadora
2. Abrí el navegador del celular
3. Ingresá: `http://192.168.0.253:8888`
4. La guía se mostrará con diseño móvil optimizado
